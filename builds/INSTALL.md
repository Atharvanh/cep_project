# Install WelNest

`WelNest.apk` is the standalone Android presentation build, version 1.0.0.

1. Copy the APK to your Android phone.
2. Open it from the phone's Files app and follow Android's installation prompts.
3. Open **WelNest** from the app launcher.

The build supports ARM64 and ARMv7 phones running Android 7 or later. Expo Go, a development server, and an internet connection are not required for the demo. The app, food photographs, and icon font are included in the APK.

The APK is signed with the project's demo signing certificate. All health results, community members, and appointments are simulated. Demo state resets when the app process restarts.

Validation completed: Android release build, APK signature verification, package/architecture checks, bundled-content checks, frontend lint, and TypeScript checks. Installation and runtime behavior have not been tested on a physical phone.

`WelNest.apk.sha256` contains the checksum for verifying the supplied file.
